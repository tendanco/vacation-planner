# 📅 Корпоративный график отпусков (Vacation Planner)

**Автор и разработчик:** Вакарина Александра
**Статус проекта:** Стабильный MVP, подготовленный к интеграции  
**Лицензия:** MIT (Разрешено корпоративное использование с сохранением авторства)

---

## 🚀 О проекте

Этот проект был придуман и разработан мной в 2026 году по **собственной инициативе** на личном оборудовании. Основная цель — решить реальную боль команды и избавиться от неудобных Excel-таблиц. 

Инструмент представляет собой наглядную интерактивную страницу-календарь, куда каждый сотрудник может самостоятельно вносить даты своего отпуска, а вся команда — видеть общую картину в режиме реального времени.

## 🛠️ Технологический стек

*   ## 🛠️ Технологический стек

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS — чистый код без тяжелых фреймворков). Everything-in-one-file архитектура (`index.html`).
*   **Backend & Database:** Firebase (Cloud Firestore & Web SDK).
*   **Hosting:** Firebase Hosting (на этапе MVP)

---

## 🔒 Безопасность и хранение данных

На этапе личной разработки приложение собирает минимальный набор данных (ФИО сотрудников и периоды отпусков) и работает на моем **приватном аккаунте Firebase**. 

> ⚠️ **Важное примечание для команды интеграции портала:**  
> В текущем виде проект завязан на мои личные ключи доступа. Для полноценного развертывания на официальном корпоративном портале компании необходимо перенести базу данных на внутренний контур инфраструктуры компании или корпоративный аккаунт Firebase.

## 🧑‍💻 Инструкция для коллег-разработчиков

Проект передается команде разработки корпоративного портала на условиях лицензии **MIT**. Вы можете форкать, клонировать, рефакторить и изменять этот код под дизайн-систему портала без моего ведома. 

**Для локального запуска:**
1. Склонируйте репозиторий: `git clone [ссылка на ваш репозиторий]`
2. Установите зависимости (если необходимо)
3. Замените конфигурационный файл Firebase на свой тестовый конфиг.

По вопросам архитектуры исходного кода, логики работы или структуры базы данных — вы можете открывать Issue в этом репозитории или писать мне напрямую в рабочий чат. С радостью помогу вам с бесшовной интеграцией!
