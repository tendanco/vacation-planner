# 📅 Корпоративный график отпусков (Vacation Planner)

**Автор и разработчик:** Вакарина Александра  
**Статус проекта:** Стабильный MVP, подготовленный к интеграции  
**Лицензия:** MIT

---

## 🚀 О проекте

Проект разработан в 2026 году по личной инициативе для замены неудобных Excel-таблиц на наглядный интерактивный календарь отпусков.

## 🛠️ Технологический стек

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS в одном файле `index.html`).
*   **Backend & Hosting:** Firebase, Firebase Hosting.

---

## 🔒 Безопасность и хранение данных

Приложение работает на приватном аккаунте Firebase автора. Для переноса на корпоративный портал необходимо настроить внутренний контур или собственный аккаунт Firebase компании.

---

## 🧑‍💻 Как взять проект в работу (Инструкция для коллег)

Файл распространяется по лицензии MIT, разрешающей адаптацию кода с помощью ИИ. 

1. Скачайте `index.html`.
2. Замените настройки `firebaseConfig` на корпоративные данные.
